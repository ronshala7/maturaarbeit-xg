# maturaarbeit-xg

## Code ausführen

### 1. Anaconda installieren
Anaconda enthält Python, Jupyter Notebook und fast alle benötigten Pakete.  
Download: https://www.anaconda.com/download

### 2. Repository herunterladen
1. Oben auf dieser Seite auf **Code → Download ZIP** klicken
2. Die ZIP-Datei **entpacken** (Rechtsklick → «Alle extrahieren»)  
   Die Notebooks nicht direkt in der ZIP-Datei öffnen, sonst werden die Excel-Dateien nicht gefunden.

### 3. Notebook öffnen und ausführen
1. **Anaconda Navigator** öffnen und bei «Jupyter Notebook» auf **Launch** klicken
2. Im Browser zum entpackten Ordner navigieren: `maturaarbeit-xg-main` → `Codes`
3. Ein Notebook öffnen, zum Beispiel `1_Modell_Open_Play_Fuss.ipynb`
4. **Kernel → Restart & Run All** wählen

Als Ergebnis erscheinen die Koeffizienten β₀ bis β₃ (siehe Tabelle 3 der Arbeit).
